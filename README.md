一. 程序用途：
通过dns劫持、tcp劫持两种方式，实现网络通信劫持。主要的方法是监听数据包，通过解析从客户端到服务端发送的tcp、udp请求，如果是攻击目标，则伪造、发送响应数据包，实现流量劫持。
由于响应时间很短(微秒级别)，所以攻击成功率几乎是100%。

二. 运行环境：
windows xp

三. 运行依赖：
1. 安装vcredist_x86.exe，出于兼容考虑。
2. 安装openssl，用于生成、管理ssl证书。
3. 安装wireshark，主要是winpcap内核驱动，从而可以调用驱动的应用程序接口发送数据包。
4. 环境搭建完成后，将winpcap开发包中的packet.dll和wpcap.dll、openssl开发包中的libssl.dll和libcrypto.dll、7z.exe和7z.dll等几个文件，复制到当前目录即可正常运行。如果还有错误，可随便找一个msvcr120.dll或者其他的msvc库移动到当前目录即可。

若绑定80、443端口失败，请使用"netstat -ano|findstr 80"、"netstat -ano|findstr 443"等命令关闭监听80、443端口的进程后，重新运行程序。

网管和dns服务器大部分情况下一致，但是某些网络是区分的，必须要正确的获取dns服务器的地址。

客户端

客户端为攻击程序。需要按照TCP/IP协议、严格组装数据包，才能达到欺骗目的。支持tcp、udp两种数据包伪造。根据winpcap接口监听到的请求数据包，伪造对应响应包返还给发送者。这是本程序的核心技术之一。
为了完成ssl/HTTP流量劫持，攻击客户端的dns请求，将目标dns请求解析到服务端。这是最简单ssl流量劫持方法之一。

服务端程序

服务端实际上就是ssl和http服务端程序。因为dns攻击已经完成，因此server程序只是监听客户端的http和ssl连接请求、检查url和host判断是否是攻击目标，如果是的话，将格式化的更新包请求发送给客户端，然后接受客户端段的更新包请求，并将后带有门程序的更新包发送给客户端。客户端运行更新包后，后门启动运行。

服务端实现了mid（中间人流量劫持），使用openssl接口完成ssl网络通信，模型为：一个客户端连接对应一个服务端线程。

主要创新点为ssl证书动态制作。证书需要预先知道域名，因此程序从ssl连接的第一个包中获取host信息、并制作证书。Recv函数第4个参数使用MSG_PEEK标记，可以预先读取数据包内容、但不清空预读内容。

配置文件:

所有的漏洞攻击都基于配置文件。即Config目录下的objects.json文件。
更新程序一般有3种，dll、exe、压缩包（其中包含更新exe或者dll），因此攻击载荷也要有3中方式。
首先调用peshell.exe将真正的木马程序services.exe和qmnetworkmgr.dll打包为一个单独的exe和dll文件。然后调用Helper.cpp中的ObjectParser函数完成攻击载荷的组装，其组装过程由objects.json决定。
App：软件名称
Valid：是否有效
Host：域名。结合url判定是否是攻击目标
url：url。结合host判定是否是攻击目标
httpFormat：http包头格式。因为每个目标的更新数据格式都不一样，因此需要配置http响应包格式。一般默认为http.exe格式，即只要需要设置Content-Length字段、Content-type字段等。

Payload：攻击载荷。
Name：载荷文件名称。
Compress：是否压缩。Zip、7z、cab等几种压缩方式。
Version：载荷版本。
Desthost：载荷下载地址的域名。有些攻击方式不支持ip，只能用域名。

Regex：攻击参数格式。即攻击数据格式参数。其中U代表url，V代表版本，M代表md5，s代表文件大小。支持多个载荷。小写字母u代表第一个载荷的url，v代表第一个载荷的版本，以此类推。


respRegex：http 响应格式。

ip地址分类：
　  1. A类地址
　　⑴ A类地址第1字节为网络地址，其它3个字节为主机地址。另外第1个字节的最高位固定为0。
　　⑵ A类地址范围：1.0.0.1到126.255.255.254。
　　⑶ A类地址中的私有地址和保留地址：
　　①10.0.0.0到10.255.255.255是私有地址（所谓的私有地址就是在互联网上不使用，而被用在局域网络中的地址）。
　　② 127.0.0.0到127.255.255.255是保留地址，用做循环测试用的。
　　2. B类地址 
　　⑴ B类地址第1字节和第2字节为网络地址，其它2个字节为主机地址。另外第1个字节的前两位固定为10。
　　⑵ B类地址范围：128.0.0.1到191.255.255.254。
　　⑶ B类地址的私有地址和保留地址
　　① 172.16.0.0到172.31.255.255是私有地址
　　②169.254.0.0到169.254.255.255是保留地址。如果你的IP地址是自动获取IP地址，而你在网络上又没有找到可用的DHCP服务器，
这时你将会从169.254.0.0到169.254.255.255中临得获得一个IP地址。
　　3. C类地址
　　⑴ C类地址第1字节、第2字节和第3个字节为网络地址，第4个个字节为主机地址。另外第1个字节的前三位固定为110。
　　⑵ C类地址范围：192.0.0.1到223.255.255.254。
　　⑶ C类地址中的私有地址：192.168.0.0到192.168.255.255是私有地址
